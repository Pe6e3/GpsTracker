# HQ Protocol (предварительное описание)

## Общие сведения

Транспорт:

```text
TCP
```

Формат основной телеметрии:

```text
*HQ,<ID>,<TYPE>,...#
```

Разделитель полей:

```text
,
```

Начало пакета:

```text
*HQ
```

Конец пакета:

```text
#
```

Идентификатор устройства:

```text
9176741221
```

---

## Пакет телеметрии V1

### Пример

```text
*HQ,9176741221,V1,113426,A,4313.8639,N,07651.8914,E,0.00,223,210626,fffffbff,401,02,13273,11499#
```

### Структура

| №  | Поле        | Пример     | Описание                     |
| -- | ----------- | ---------- | ---------------------------- |
| 1  | Prefix      | HQ         | Тип протокола                |
| 2  | DeviceId    | 9176741221 | Идентификатор устройства     |
| 3  | PacketType  | V1         | Телеметрия                   |
| 4  | Time        | 113426     | Время HHMMSS                 |
| 5  | GPSStatus   | A          | GPS валиден                  |
| 6  | Latitude    | 4313.8639  | Широта в формате ddmm.mmmm   |
| 7  | NS          | N          | Север/Юг                     |
| 8  | Longitude   | 07651.8914 | Долгота в формате dddmm.mmmm |
| 9  | EW          | E          | Восток/Запад                 |
| 10 | Speed       | 0.00       | Скорость                     |
| 11 | Course      | 223        | Курс                         |
| 12 | Date        | 210626     | Дата DDMMYY                  |
| 13 | StatusFlags | fffffbff   | Битовая маска состояния      |
| 14 | Field14     | 401        | Назначение неизвестно        |
| 15 | Field15     | 02         | Назначение неизвестно        |
| 16 | Field16     | 13273      | Назначение неизвестно        |
| 17 | Field17     | 11499      | Назначение неизвестно        |

### Координаты примера

Исходные:

```text
4313.8639,N
07651.8914,E
```

Десятичные:

```text
43.231065
76.864857
```

## Подтверждение сервера R12

### Пример

```text
*HQ,9176741221,R12,113432#
```

### Структура

| Поле       | Пример     |
| ---------- | ---------- |
| Prefix     | HQ         |
| DeviceId   | 9176741221 |
| PacketType | R12        |
| Time       | 113432     |

### Назначение

Подтверждение получения пакета (ACK).

Устройство ожидает ответ вида:

```text
*HQ,<ID>,R12,<TIME>#
```

После получения подтверждения продолжает работу штатно.

Наблюдаемые пакеты:

```text

11:40:33 V1
11:43:33 V1
```

```text
≈ 180 секунд
```

```text
T:20-300-180
```

Предположительно:

```text
180 секунд — период передачи телеметрии
```

## Бинарный пакет

### Пример

```hex
24 91 76 74 12 21 11 40 51
21 06 26
43 13 86 39
64
07 65 18 91
0E 00
02
23
FF FF FB FF
00 00 0F F7
00 00 00 00
01 91
02 33
D9 2C
EB 16
```

Длина:

```text
45 байт
```

Особенности:

* Приходит примерно раз в 5 минут.
* После него сервер отвечает пакетом R12.
* Содержит дату и координаты, совпадающие с текстовой телеметрией.
* Первый байт всегда:

```hex
24
```

ASCII:

```text
$
```

Предположительно представляет собой расширенную телеметрию или пакет состояния устройства.

Структура пока не определена.

## Известные типы пакетов

| Тип           | Направление     | Назначение                         |
| ------------- | --------------- | ---------------------------------- |
| V1            | Device → Server | GPS телеметрия                     |
| R12           | Server → Device | Подтверждение получения            |
| Binary ($...) | Device → Server | Неизвестно, требуется исследование |

## Вывод

Устройство использует собственный текстовый протокол семейства:

```text
*HQ,...#
```

Протокол не относится к семейству GT06 (`7878...`) и отличается от Jointech, HHD и Naviline.

Для минимальной поддержки устройства на сервере достаточно:

1. Принимать пакет `V1`.
2. Извлекать координаты, время и дату.
3. Отправлять подтверждение:

```text
*HQ,<ID>,R12,<TIME>#
```

где `<ID>` — идентификатор устройства, `<TIME>` — текущее время сервера в формате HHMMSS.
