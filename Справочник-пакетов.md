# Справочник типов пакетов JT/T808

Используется прокси для расшифровки логов. В основном терминале выводятся только пакеты **от устройства к серверу**.

## Терминал → платформа

| Код    | Название в логе              | Описание                              |
| ------ | ---------------------------- | ------------------------------------- |
| 0x0001 | ответ терминала              | Общий ответ терминала                 |
| 0x0002 | **пульс**                    | Heartbeat, keepalive                  |

| 0x0100 | **регистрация**              | Первичная регистрация устройства      |

## Пакеты, наблюдаемые на устройстве 19176726768

| Код    | Название       | Частота              |
| ------ | -------------- | -------------------- |
| 0x0102 | аутентификация | При подключении      |
| 0x0200 | телеметрия     | ~ каждые 20 секунд   |
| 0x0002 | пульс          | Периодически         |

## Формат строки в терминале

```text
[06.06.2026 11:23:48] [9176726768] Тип пакета: телеметрия 43.231021, 76.864583 alt=842m speed=1.8km/h dir=263° time=2026-06-06 17:01:48
[06.06.2026 11:23:48] [9176726768] Тип пакета: аутентификация token=19176726768
[06.06.2026 11:23:50] [9176726768] Тип пакета: пульс
```

Номер устройства в логе — без ведущей «1» (11-значный terminal ID → 10 цифр).
